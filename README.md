# Haven Estates

Haven Estates is a modern, premium real estate website designed to provide a seamless property discovery experience. It allows users to explore properties for sale and rent, view detailed property information, learn about real estate services, and make enquiries.

The project focuses on delivering a professional, elegant, and user-friendly digital experience through clean layouts, intuitive navigation, responsive design, and carefully structured content.

## Key Features

- Modern and responsive homepage
- Property listings for sale and rent
- Property details and image galleries
- About Us page
- Real estate services showcase
- Contact and property enquiry page
- Responsive navigation and user-friendly interface

## Project Goal

To create a professional digital platform that makes property discovery easier while establishing a strong and trustworthy online presence for a real estate company.
